# Сервис управления данными пользователей 
### Проект выполнен в рамках технического задания от компании **Yadro**

Асинхронное веб-приложение на базе FastAPI для сбора, хранения и отдачи информации о пользователях, интегрированное с внешним генератором случайных данных.

---

## Обоснование технологического стека

* **FastAPI**: Выбран в качестве веб-фреймворка из-за встроенной поддержки асинхронности, что важно для высоконагруженных сетевых запросов к внешнему API и базе данных. Дополнительным преимуществом является автоматическая генерация документации OpenAPI и валидация типов данных через Pydantic.
* **SQLAlchemy (v2.0) + asyncpg**: Использование ORM позволяет работать с базой данных при помощи python-объектов. Драйвер `asyncpg` обеспечивает максимальную скорость работы с PostgreSQL в асинхронном режиме.
* **Alembic**: Инструмент миграций интегрирован для обеспечения версионирования схемы базы данных.
* **PostgreSQL**: Выбрана в качестве СУБД, так как она обеспечивает 
* поддержку ACID, имеет асинхронный драйвер `asyncpg` и является одним из стандартов разработки.
---

## Паттерны проектирования

* **Repository Pattern**: Вся работа с базой данных и построение SQL-запросов изолированы в классе `PersonRepository`. Это отделяет логику хранения от бизнес-логики и позволяет менять источник данных без изменения остального кода.
* **Dependency Injection**: Жизненный цикл сессий базы данных, репозиториев и сервисов контролируется механизмом зависимостей FastAPI (`Depends`). Это обеспечивает слабую связанность компонентов.
* **Data Transfer Object**: Для разграничения внутренней структуры базы данных и внешних контрактов API используются Pydantic-схемы. Это гарантирует строгую валидацию входящих параметров и безопасный формат ответов.

## Структура проекта

```text
├── alembic/                  # Миграции базы данных Alembic
├── src/                      # Исходный код приложения
│   ├── api/                  # Маршруты и эндпоинты API
│   ├── core/                 # Общие настройки приложения
│   ├── db/                   # Слой работы с базой данных
│   │   ├── models/           # SQLAlchemy-модели
│   │   ├── repositories/     # Запросы к базе данных
│   ├── schemas/              # Pydantic-схемы для валидации запросов и ответов
│   ├── services/             # Слой бизнес-логики (PeopleService, API-клиенты)
│   ├── startup/              # Скрипты, выполняемые при старте сервера
│   ├── exceptions.py         # Кастомные исключения приложения
│   └── main.py               # Точка входа
├── tests/                    # Тесты (pytest)
├── Dockerfile               
├── docker-compose.yml        
├── pyproject.toml           
└── requirements.txt          
```

## Инструкция по запуску

1. Клонируйте репозирий

```bash
git clone https://github.com/vettta06/random_peoples_api
```

2. Создайте env-файл по аналогии с env.example

```bash
cp .env.example .env
```

3. Запустите docker

```bash
docker-compose up --build
```

4. Откройте браузер и перейдите на страницу документации

 - http://127.0.0.1:8000/docs


5. Запуск тестов

```bash
poetry run pytest
```
